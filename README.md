# CodeLab

🌐 CodeLab est un mini‑projet de site internet en **français**.  
Il enseigne pas à pas comment créer des sites web modernes avec HTML, CSS et JavaScript.  
Le site inclut une page d’accueil, un blog, une section services, une page "À propos" et une page de confidentialité.
